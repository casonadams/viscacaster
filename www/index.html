ViscaCaster

Universal desktop application for VISCA PTZ camera control (Serial & Network IP) paired with an embedded 60 FPS broadcast presentation engine for worship services and live events.

⬇ Download Latest Release View on GitHub

🎥 Universal VISCA Control

Supports both Serial RS-232/USB adapters (Keyspan, FTDI, CP210x, CH340) and VISCA-over-IP (UDP port 52381 / 1259) across Sony, PTZOptics, BirdDog, and generic PTZ cameras.

🔍 3-Tier Auto-Discovery

Instant camera detection via active VISCA serial handshake, USB hardware vendor filtering, and local network ONVIF WS-Discovery probe with one-click latching.

🎵 LDS Hymn Engine (1–341+)

Embedded 341-hymn index from Hymns of The Church of Jesus Christ of Latter-day Saints. Instant lookup by number (e.g. 193), title search, and live verse carousel.

🏷️ Broadcast Lower Thirds

Animated lower thirds for speakers, conducting officers, and sermon titles. Smart Director automatically triggers lower thirds when recalling Preset 1 (Podium).

📢 Marquee Announcement Ticker

Hardware-accelerated 60 FPS scrolling ticker along the bottom of the broadcast feed for meeting times, nursery, and fellowship announcements.

⚡ Rock-Solid Rust Core

Built with egui and pure Rust. Single self-contained binary, zero C/GTK runtime baggage, zero crash risk for OBS, and instant launch on Windows, macOS, and Linux.

OBS Studio 30-Second Setup

ViscaCaster embeds an internal web server that delivers transparent 60 FPS graphics directly to OBS Studio:

http://localhost:8080/overlay
  1. In OBS Studio, click [+] under Sources and select Browser.
  2. Set the URL to http://localhost:8080/overlay.
  3. Set Width to 1920 and Height to 1080.
  4. Uncheck "Shutdown source when not visible" and check "Refresh browser when scene becomes active".
  5. Position this Browser source above your camera video source.
